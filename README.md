# NewsWatcherBot 🤖

Telegram бот для мониторинга новостных каналов. Автоматически собирает посты из указанных каналов и предоставляет удобный доступ через Telegram интерфейс.

## ✨ Возможности

- 📊 **Мониторинг каналов** - отслеживание нескольких Telegram каналов одновременно
- 💾 **Локальное кэширование** - сохранение сообщений в SQLite базу данных
- 🔄 **Автообновление** - ручное и автоматическое обновление кэша сообщений
- 📱 **Удобный интерфейс** - инлайн-кнопки для быстрой навигации
- 🧹 **Чистые сообщения** - автоматическое удаление HTML тегов из постов
- 🔒 **Безопасность** - защищенное хранение конфиденциальных данных

## 🚀 Быстрый старт

### 1. Установка зависимостей

# Клонируйте репозиторий
git clone <my-repo-url>
cd newswatcher

# Установите зависимости
pip install -r requirements.txt
2. Настройка конфигурации
bash
# Создайте файл конфигурации из примера
cp .env.example .env

# Отредактируйте .env файл
nano .env
Заполните .env файл:

env
# Обязательные параметры:
BOT_TOKEN=your_bot_token_here              # Токен от @BotFather
TG_API_ID=your_api_id_here                 # API ID от my.telegram.org
TG_API_HASH=your_api_hash_here             # API Hash от my.telegram.org

# Опциональные настройки:
DB_PATH=news.db                            # Путь к базе данных
PAGE_SIZE=5                                # Сообщений на страницу
DEFAULT_CHANNELS=@durov,@telegram,@news    # Каналы для мониторинга

3. Получение API ключей - 

🔑 Токен бота:
Напишите @BotFather в Telegram

Используйте команду /newbot

Следуйте инструкциям и сохраните полученный токен

🌐 API ID и Hash:
Перейдите на my.telegram.org

Авторизуйтесь своим аккаунтом Telegram

Перейдите в раздел "API Development Tools"

Создайте новое приложение и сохраните api_id и api_hash

4. Запуск бота
Первый запуск (требует авторизации):

 - cd app
 - python main.py
Процесс авторизации:

📱 Бот запросит номер телефона (в формате +79123456789)

🔐 Вы получите код в официальном приложении Telegram

⌨️ Введите полученный код в консоль

🔑 При наличии 2FA введите пароль

✅ Авторизация завершена!

Последующие запуски:

 - cd app
python main.py

📋 Команды бота
Команда	Описание	Пример
/start	Главное меню с списком каналов	/start
/channels	Показать все доступные каналы	/channels
/refresh	Обновить кэш всех каналов	/refresh

🎯 Как использовать
Запустите бота командой /start

Выберите канал из списка кнопок

Просматривайте последние 5 сообщений

Обновляйте кнопкой "Обновить" при необходимости

🔧 Технические детали - 

Используемые технологии:
Aiogram 3.10+ - современный фреймворк для Telegram ботов

Telethon - мощная библиотека для работы с Telegram API

SQLite - легковесная база данных для кэширования

Python-dotenv - управление переменными окружения

Особенности реализации:
Синглтон паттерн для Telethon клиента

Автоматическая авторизация при первом запуске

Очистка HTML тегов из сообщений каналов

Обработка ошибок с подробным логированием

Валидация входных данных и форматов каналов

🔒 Безопасность
Защита данных:
.env файл исключен из Git через .gitignore

Токен бота дает ограниченный доступ только к функционалу бота

API ключи требуют дополнительной авторизации через номер телефона

Все чувствительные данные хранятся локально

Рекомендации по безопасности:

🔑 Никогда не публикуйте .env файл

🔄 Регулярно обновляйте зависимости

🛑 Используйте разные API ключи для разных проектов

📱 Храните бэкапы сессий в безопасном месте
